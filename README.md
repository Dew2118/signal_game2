# Signal Game

## Installation Instructions

1. Download code as zip
2. Unzip the folder
3. Open command prompt and navigate to the repo folder:
   ```
   cd Downloads/signal_game2-main/signal_game2-main
   ```
4. Run `python --version` to check if you have Python installed and added to PATH. If it errors with "command python not recognized", you must install Python from the Microsoft Store.
5. Install the required Python packages:
   ```
   pip install -r requirements.txt
   ```
6. Run the game:
   ```
   python .
   ```

## Gameplay

1. Choose a zone (do not choose "test" - any other zone will work)
2. Set signals by clicking on the entrance signal, then the exit signal
3. Cancel a route by right-clicking the entrance signal
4. Check the schedule by clicking on the train's headcode

## Controls

| Key | Action |
|-----|--------|
| `P` | Pause/Unpause |
| `Numpad +` | Speed up game |
| `Numpad -` | Slow down game |
| `Ctrl + S` | Save |
| `Ctrl + L` | Load |
| `Ctrl + R` | ARS: **EXPERIMENTAL, MAY DESTROY THE GAME, ZONE 6 ONLY** |
